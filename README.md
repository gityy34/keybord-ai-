# Raabta Keyboard 0.3.0

Install raabta-keyboard-0.3.0.apk over the existing Raabta app. Same retained debug signing certificate.

Gear opens category settings inside the keyboard. Features include Space cursor sliding, a stable word/emoji suggestion strip, local Urdu/Roman Urdu layouts, held/flick symbols, font/emoji size, feedback controls, one-handed/floating modes, editor tools, clipboard/optional contact/screenshot previews, and an original offline sticker/GIF pack. Existing buffered voice Stop/pause controls are retained.

85 tests passed; Android lint 0 issues; APK v2 signature verified. Optional contacts/photo access is requested only after enabling the relevant control. Image/GIF paste and undo depend on the receiving app. Dictionaries, grammar rules and glide matching are starter offline implementations; online GIF search, translation and AI are not connected. OPPO performance/compatibility acceptance is still required.
