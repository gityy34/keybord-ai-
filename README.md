# Raabta Keyboard 0.2.1

Install raabta-keyboard-0.2.1.apk over the existing Raabta app. Same debug signing certificate as 0.2.0.

Dictation buffers speech until Stop or the selected long silence. Settings offer manual Stop only, 8 seconds (default), or 12 seconds; Fast finish (800 ms with an available draft) or Prefer-final (up to 3 seconds). Without any available draft Fast also waits up to 3 seconds. Provider recognition, Urdu accuracy and audio gaps between restarted utterances still require phone validation.

Use Urdu-only voice for Urdu phrases; mixed English + Urdu starts with Urdu unless Mostly English is selected. Leave On-device only off for the initial test. Backspace hold and repeat timing controls are available alongside theme, height, number row and sound/vibration settings.

56 tests passed; Android lint 0 issues. APK v2 signature verified. RECORD_AUDIO only; the separate system speech service can process audio online. No transcripts or recordings are stored by Raabta.

Download in Chrome, sign in to GitHub with repository access, then choose View raw/Download raw file. If an in-app browser opens a page without downloading, open this file page in Chrome:
